## 2. 源码与本机只读核查结论

### 2.1 已有能力与缺口

- `backend/app/services/daban_compute.py::build_tags` 是旧标签公式依据；旧样本来自事件池，不是全股票-日期样本。`daban_lab.py::build_touch_board/build_trades` 的默认触板池可含炸板，不能假设所有review样本必然收盘涨停。

- DSL已有 `if_else/min/max/ts_qlinear`、算术与比较；**不需要为了这次任务泛化信号OR或增加任意Python执行能力**。`ts_qlinear` 是线性分位，不能错用默认nearest的 `ts_quantile`。
- 普通信号最多8个AND条件；`strict_signal_data.py` v1只校验OHLC/amount。`custom_signals.py` 字段白名单虽然已有连板、raw价格和运行时涨停价，却不代表严格契约已支持这些字段。

- `registry.py/scoring.py` 已有20/60日涨停次数、20日摸板未封次数、涨停次日开盘溢价。前两类当前内部把缺失填成0/false，**不可直接作为本批严格窗口的无缺失证据**；新增严格因子不改变旧因子语义。
- `share_capital.py` 现有功能是历史流通股本，且缺公告日可退回报告期、缺历史可退回最新股本；这不满足本次历史总市值合同。不能把流通市值替代总市值。

## 3. 一次批准需要覆盖的统一口径（推荐）

### 3.1 时间与样本

- D始终是信号行日期；pre原D=T-1，review/event原D=T，bit13原D=T+1。每条公式按自己的D取数据，不统一机械再偏移一天。
- **本轮全部落为收盘后可用的普通日线信号。** bit13虽开盘时已知，本轮不承诺开盘实时计算，不启用竞价或盘中路径；记录在D而不是原事件日D-1。
- 全股票-日期计算，不用“未来已经涨停/未来收益可算”筛样本。技术信号不等于有效策略，也不触发交易。
- 不把T+1收盘一字板归到T；不把一字形态直接等同实际无法成交。

### 3.2 数据与三态

- OHLC为同一复权口径的有限正数且关系合法；amount有限非负，作为分母时必须>0。市场日历连续、重复/缺行/乱序按已有严格纪律处理。
- 带事件/市场依赖的新定义使用向后兼容的严格契约v2（**拟新增**）；v1及已有56个定义不修改。v2显式声明每类字段窗口、合法范围、来源有效性及数据可用时点。
- 涨停事实使用未复权价与同日可核验涨停价；历史身份/限价不可核验时unknown，不以9.5%近似，不把CLU缺失填0。已知无涨跌幅限制与“资料缺失”分开：已知不适用的涨停事件可判false，资料不明为unknown。
- 缺少历史涨停候选但窗口完整时，“没有候选”是false，而非缺数据。原始条件峰值保留null无候选语义。用于组合的数值特征可定义为“窗口内事件收盘相对当前收盘的最大倍数”：完整窗口无事件时按该聚合合同输出0，有事件时输出P/C；信号同时要求候选数>=1。这样不会把空候选的null操作数错误升级为unknown，也不虚构峰值价格或使用零分母。窗口/当前收盘/事件资料缺失时该聚合仍为null，不允许填0。
- 新因子自身也必须保留未知/有效性，不能只有最终信号守卫，导致以后因子探索复用错误数值。金额零、无事件与未知分别验收。
- 不自动引入全局容差。第十二批局部8eps政策不传播到本批；如某个新严格边界需要额外数值政策，带失败用例重新确认。

### 3.3 事件、命名及经验阈值

- C组凡名称指“板”的形态，推荐明确要求**D收盘封板**；不再继承旧触板事件池的隐含前提。这比旧默认触板池更严格，是**待批准的语义变化**。若用户希望触板含炸板版本，应在实施前改为另一套明确命名，不同时默认增加两套。
- bit33保留源码“前阴、当日收盘越前开、高点抬升、额比”的条件，改客观名称；不宣称完整实体吞没，不偷偷添加源码没有的当日开盘覆盖条件。
- bit45改为“大阳实体与振幅封板”，不称真实换手率条件；bit75使用实际摸板未封事实，不再把长上影叫炸板。
- bit90采用旧注释意图的历史窗口并修正命名说明：原T-8..T-20=D-7..D-19；平台原T-2..T-6=D-1..D-5。旧代码实际用了D..D-19的9.5%涨幅和D-2..D-6平台，不能声称等价迁移。
- bit58/59/60保留0.0598/0.1781，bit85保留0.379，bit92保留0.509，命名为**固定经验阈值预设**，不称当前市场分位点、不重新全样本拟合。旧阈值源自2026-11-16前后全样本探查，历史回放只能视作描述性结果，不能冒充样本外验证。新自动探索日后必须在训练折内校准，验证/测试折冻结；本轮不启动校准或优化。

## 4. 全部38条公式与迁移映射

记号：`X[k]=X[D-k]`；`max(X,a:b)`/`min`/`mean`为闭区间偏移a..b；`R[k]=C[k]/C[k+1]-1`；`MA_n[k]=mean(C,k:k+n-1)`；`B=abs(C-O)`、`U=H-max(O,C)`、`Lw=min(O,C)-L`。

`S[k]`=已核验收盘涨停事实；`K[k]`=已核验截至当日连续收盘涨停数；`Z[k]`=已核验当日摸板未封。`N(a:b)=sum(S[a:b])`；`P(a:b)=max(C[k] where S[k]=1)`，仅在完整窗口且N>0时有值。不得用事后最终连板长度。

实现P相关条件时优先用上一节的事件相对价最大倍数Q及候选数：C/P<=0.95对应Q>=1/0.95，C/P<=0.97对应Q>=1/0.97，C>P对应Q<1；空集合的Q=0仅在候选数=0且完整有效时成立。该实现仍须边界回归，不因代数等价假定浮点必然等价。

表中的OHLC N表示D..D-N+1全部完整；列出的amount窗口也必须连续。事件源依赖另需原始价格/前收及身份有效性，不能用OHLC窗口替代。保留部分旧full21的保守校验，不悄悄减窗。
