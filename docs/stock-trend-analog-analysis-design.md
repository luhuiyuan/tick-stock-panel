# 基于历史类比走势的后市路径分析设计

- **文档状态**：设计中
- **文档类型**：研究方案与后续实现设计
- **适用范围**：A 股个股日线历史类比、走势检索、条件收益分布
- **当前版本**：v1.0
- **日期**：2026-10-11
- **前置文档**：[`stock-trend-context-pattern-design.md`](./stock-trend-context-pattern-design.md)

## 1. 方案定位

本方案用于回答：

> 当某只股票当前的 L0/L1/L2 市场结构、波段进展和近期 K 线形态，与历史上的一批状态相似时，这些历史样本之后通常出现什么走势？

系统输出的是历史条件分布和类比路径，不直接声称未来一定上涨或下跌，也不直接生成实盘交易信号。

核心思路是：

```text
历史前缀重放
→ 提取当时可见的结构化状态
→ 检索历史相似状态
→ 连接相似状态之后的真实未来路径
→ 输出收益分布、方向概率和风险分位数
```

本方案优先解决历史检索和统计验证问题，只有在滚动样本外实验显示稳定信息增量后，才考虑接入选股、风控或 AI 分析。

## 2. 与现有实现的边界

### 2.1 当前已实现能力

当前生产代码已经提供：

- 日线市场结构 `L0/L1/L2`；
- L0 使用窗口 3，L1 使用窗口 7，L2 使用窗口 15；
- 各层直接处理原始日线，不是逐级递归聚合；
- 已确认 `segments`；
- L1/L2 的 `current_tail`；
- 结构点的确认日期；
- 日线、周线、月线图表展示；
- 基于历史前缀的离线 L2 表达式实验基础。

### 2.2 本方案拟增加的研究能力

- 历史前缀状态快照；
- L0/L1/L2 连续结构特征；
- 最近 K 线的波动率归一化形态特征；
- 精确表达式匹配基线；
- 结构约束的连续特征近邻匹配；
- 固定时间窗口和下一个 L2 事件的未来路径统计；
- 股票级、时间级和滚动样本外验证。

### 2.3 明确不包含的内容

本方案暂不实现：

- 生产股票分析 API 改造；
- 前端页面和实时刷新；
- 自动买卖信号；
- 自动参数优化；
- 直接训练黑盒深度学习模型；
- 无样本外验证的实盘策略；
- 将最终结构结果直接用于历史回测。

## 3. 为什么不继续依赖精确趋势表达式

趋势表达式仍然有价值，但更适合作为：

```text
解释标签
索引键
历史复盘标识
精确匹配基准
```

不宜作为唯一的相似度定义，原因是：

1. 时间和幅度一旦分箱，连续差异会被隐藏；
2. 分箱过粗会把不同走势混在一起；
3. 分箱过细会导致模式稀疏；
4. K=2、K=3 增加上下文后，跨股票命中率快速下降；
5. 完全相同的表达式不代表市场环境、波动率和当前位置相同。

因此采用双层表示：

```text
字符串表达式：用于展示、索引和精确匹配
结构化连续特征：用于相似度计算和近邻匹配
```

## 4. 历史前缀重放与未来函数隔离

### 4.1 观察日语义

对每个观察日 `t`，系统只能使用：

```text
原始行情日期 <= t
```

生成：

```text
L0/L1/L2 结构
已确认波段
截至 t 的 current_tail
当前连续特征
当前趋势表达式
```

然后才能读取：

```text
t+1 到 t+H
```

作为未来收益标签。

### 4.2 不得使用最终结构回填历史

当前结构会随着新增 K 线而修正。特别是 L2 需要左右各 15 根 K 线确认，今天看到的历史拐点，可能在历史观察日 `t` 尚未确认。

因此禁止：

```text
先用今天的完整 L2 结构计算所有历史日期特征
```

必须：

```text
数据截断到 t
→ 重新运行同一套市场结构算法
→ 使用当时可见的结果
→ 再连接未来标签
```

历史重放结果只服务研究实验，不覆盖生产中的当前结构结果。

### 4.3 当前尾段

对于 L1/L2：

```text
current_tail = 截至 t 从最后一个已确认拐点到当前收盘的临时段
```

当前段只使用截至 `t` 已经发生的：

- 方向；
- 持续交易日数；
- 已实现净变化；
- ATR 标准化变化。

不得使用未来最终确认后的完整持续时间或最终幅度。

如果某个观察日没有可可靠定义的当前段，应跳过该样本，而不是用未来确认后的波段补齐。

## 5. 状态特征设计

每个观察日生成一个结构化快照。示例：

```json
{
  "symbol": "603920.SH",
  "date": "2026-10-09",
  "l2": {
    "state": "DOWN",
    "duration": 18,
    "net_return": -0.12,
    "amplitude": 0.12,
    "return_atr": -2.4,
    "distance_from_anchor": -0.08
  },
  "l1": {
    "state": "UP",
    "duration": 9,
    "net_return": 0.06
  },
  "l0": {
    "state": "UP"
  },
  "alignment": {
    "l0_l1_same_direction": true,
    "l1_l2_same_direction": false,
    "all_same_direction": false
  }
}
```

### 5.1 当前 L2 特征

优先保留连续值：

```text
state
actual_duration
net_return
absolute_amplitude
net_return / ATR
current price / L2 start price - 1
current price relative to latest confirmed high/low
```

其中：

- `duration` 使用交易日数量，不使用自然日；
- `net_return` 使用当前项目波段端点净变化口径；
- ATR 归一化只作为相似度特征，不改变当前市场结构算法；
- 真实连续值必须保留，即使同时存在离散表达式。

### 5.2 前序 L2 波段

可保留最近 2～3 个已完成 L2 波段：

```json
[
  {"state": "DOWN", "duration": 43, "net_return": -0.21},
  {"state": "UP", "duration": 31, "net_return": 0.18},
  {"state": "DOWN", "duration": 18, "net_return": -0.12}
]
```

前序波段主要用于：

- 方向切换模式；
- 波段幅度比例；
- 波段持续时间比例；
- 当前段处于前序结构的何种位置。

不要求前序波段数值完全相同，而是进入连续距离计算。

### 5.3 L0/L1/L2 对齐特征

多级别关系用于区分同一个 L2 状态内部的不同短中期阶段：

```text
L2 DOWN + L1 UP + L0 UP
L2 DOWN + L1 DOWN + L0 DOWN
```

至少保留：

```text
L0 当前方向
L1 当前方向
L2 当前方向
L0/L1 是否同向
L1/L2 是否同向
L0 是否刚发生方向切换
L1 是否刚发生方向切换
L2 是否刚发生方向切换
```

这比把 L0/L1/L2 直接拼接成一个超长字符串更不容易稀疏。

### 5.4 最近 K 线形态

最近 10～30 根日线可以提取：

```text
close return / ATR
(high - low) / ATR
(close - open) / ATR
上影线 / ATR
下影线 / ATR
成交量相对过去均值的变化
滚动波动率
```

不直接比较绝对价格，也不直接比较未归一化的 K 线高度。

建议第一版使用最近 20 根日线，并保留：

```text
标准化收益序列
实体长度序列
上影线/下影线序列
```

## 6. 趋势表达式兼容设计

### 6.1 表达式用途

趋势表达式仍然生成，但主要用于：

- 研究报告；
- 历史复盘；
- 精确匹配基线；
- 近邻结果解释；
- 结果缓存键。

### 6.2 表达式变体

保留三种变体进行对照：

```text
state
state + amplitude
state + time + amplitude
```

示例：

```text
D,U#D
D_35,U_25#D_12
D_20_35,U_20_25#D_10_12
```

幅度不再将所有 20% 以上走势统一为 30。建议使用较细但有限的档位，同时保留真实幅度：

```text
0～3%
3～5%
5～8%
8～12%
12～18%
18～25%
25～35%
35～50%
50%以上
```

### 6.3 连续上下文

表达式可以保留 K=1、K=2、K=3：

```text
K=1：上一个已完成波段#当前波段
K=2：倒数第二个波段,上一个波段#当前波段
K=3：倒数第三个波段,倒数第二个波段,上一个波段#当前波段
```

但 K 越大越容易稀疏。正式匹配默认优先：

```text
L2/K=1
L2/K=2 作为对照
L2/K=3 不作为第一版硬条件
```

## 7. 相似度与历史近邻

### 7.1 两阶段候选筛选

不直接对所有历史日期计算复杂距离。先进行结构候选筛选：

```text
1. L2 当前方向一致；
2. L1/L2 关系相同或相近；
3. 当前段 ATR 标准化幅度处于合理范围；
4. 当前段持续时间处于合理范围；
5. 最近 K 线窗口长度一致。
```

然后对候选样本计算连续距离。

### 7.2 综合距离

建议初始距离：

```text
distance =
    0.35 × L2 连续结构距离
  + 0.25 × L0/L1/L2 对齐距离
  + 0.25 × 最近 K 线形态距离
  + 0.15 × 波动率/成交量距离
```

权重只是初始研究参数，不能根据测试集结果反复调优。正式参数必须在实验配置中固定并记录版本。

### 7.3 连续特征距离

可使用经过稳健标准化的加权距离：

```text
duration_distance
amplitude_distance
ATR_normalized_return_distance
position_distance
```

对于最近 K 线形态：

- 第一版可使用固定长度后的加权欧氏距离；
- 若形态出现时间平移，再测试 DTW；
- DTW 只能作为近邻距离，不改变未来标签和验证边界。

### 7.4 K 个近邻

当前状态得到候选历史样本后，取：

```text
K=20、K=30、K=50
```

分别输出结果，检查概率和分位数是否稳定。

如果 K 过小，结果容易受单个极端样本影响；如果 K 过大，结构条件会被稀释。

## 8. 未来走势标签

### 8.1 固定交易日窗口

至少统计：

```text
未来 5 个交易日收益
未来 10 个交易日收益
未来 20 个交易日收益
未来 40 个交易日收益
```

统一使用：

```text
close[t+h] / close[t] - 1
```

其中 `h` 按交易日索引，不按自然日计算。

### 8.2 方向分类

不建议只用正负号分类。可以同时输出原始正负统计和带死区分类：

```text
上涨：收益 >= +阈值
下跌：收益 <= -阈值
横盘：介于两者之间
```

阈值候选：

```text
固定 2%
或 1 × 当前 ATR 标准化阈值
```

阈值必须在实验开始前固定，不能按测试结果调整。

### 8.3 未来路径分布

每个观察窗口至少返回：

```text
样本数
上涨概率
下跌概率
横盘概率
平均收益
中位收益
P10/P25/P50/P75/P90
正收益样本平均收益
负收益样本平均收益
```

用户最终看到的应类似：

```text
未来 20 日：
正收益概率：57%
中位收益：+3.1%
P25：-4.8%
P75：+9.7%

上涨样本平均：+11.2%
下跌样本平均：-8.4%
```

### 8.4 MFE/MAE

对未来窗口 `H`：

```text
MFE_H = max(high[t+1:t+H]) / close[t] - 1
MAE_H = min(low[t+1:t+H]) / close[t] - 1
```

MFE/MAE 用于描述路径风险，不作为额外特征输入当前匹配。

### 8.5 下一次 L2 事件

除固定窗口外，可以统计：

```text
下一次 L2 方向确认
下一段 L2 方向
下一段 L2 净变化
下一段 L2 持续时间
下一段最大有利/不利幅度
```

尚未出现下一次确认拐点的样本必须标记为删失：

```text
censored = true
```

不能把它们强行归类为上涨或下跌失败样本。

## 9. 样本重叠和重复模式

### 9.1 日级样本

每个交易日可以形成一个观察样本，适合回答：

> 在每天看到这种状态时，未来收益如何？

但连续多天可能来自同一个 L2 当前段，因此样本相关性很高。

### 9.2 事件级样本

同一个 L2 当前段只保留一个代表样本，建议使用：

```text
symbol + current_l2_segment_start_date
```

作为事件标识。

事件级样本适合回答：

> 这种结构历史上独立出现过多少次？

### 9.3 重复表达式报告

对每个表达式输出：

```text
出现次数
涉及股票数
涉及年份数
首个/最后出现日期
所属 L2 事件数
测试集命中次数
```

一个模式只有在跨股票、跨时间段重复出现时，才值得进入后续统计。

## 10. 验证设计

### 10.1 基线模型

至少比较：

```text
模型 0：无条件未来收益
模型 1：仅 L2 当前方向
模型 2：精确趋势表达式
模型 3：结构约束的连续特征近邻
```

模型 3 必须同时与模型 0 和模型 1 比较，不能只报告自身命中样本的收益。

### 10.2 股票级留出

训练股票与测试股票完全分离：

```text
训练股票：构建历史模式库
测试股票：只用于样本外评估
```

测试股票的任何历史表达式和未来标签，在模式库构建阶段都不可见。

### 10.3 时间级留出

训练模式只能使用训练时间边界之前的样本。推荐：

```text
训练期：前 70%
测试期：后 30%
```

严格模式同时要求：

```text
训练股票 + 训练期 → 训练模式库
测试股票 + 测试期 → 最终测试
```

### 10.4 Walk-forward

正式评估时使用滚动方式：

```text
每个评估日期 t：
只使用 t 之前已经完成标签的历史样本
匹配 t 的当前状态
记录 t 之后的未来路径
```

模式库可以按月更新，但不能使用当前测试窗口之后的样本。

### 10.5 Purged / embargo

如果未来标签最大观察期为 40 个交易日，训练和验证边界之间至少保留 40 个交易日的 embargo，避免标签区间重叠。

### 10.6 评价指标

重点评价：

```text
覆盖率：测试日中有多少能找到足够近邻
方向准确率
Brier score 或概率校准误差
平均收益与中位收益
下行尾部 P10/P25
MFE/MAE
不同年份和不同股票的稳定性
```

不以“上涨概率超过 50%”作为单独成功标准。

## 11. 最小可行研究流程

### 阶段 1：前缀特征生成

产出：

```text
每只股票、每个历史观察日的 L0/L1/L2 快照
连续结构特征
表达式
未来收益标签
```

验证：

```text
随机抽样检查前缀不能读取未来；
确认日期和 current_tail 语义正确；
未来收益索引按交易日对齐。
```

### 阶段 2：精确表达式基线

产出：

```text
state
state + amplitude
state + time + amplitude
K=1/K=2/K=3
```

目的：

```text
测量重复率、覆盖率和样本稀疏程度。
```

### 阶段 3：结构约束近邻

产出：

```text
候选筛选
加权距离
K 个近邻
未来收益分布
```

与精确表达式在同一时间和股票留出条件下对比。

### 阶段 4：路径统计

增加：

```text
MFE/MAE
未来收益分位数
下一次 L2 事件
路径叠加图
```

### 阶段 5：市场环境分层

在个股结构稳定后，再加入简单环境变量：

```text
指数 L2 状态
指数近期收益
市场波动率
上涨股票比例
```

不在前几阶段同时引入过多行业和宏观变量。

## 12. 结果解释规则

### 12.1 可以说什么

如果样本外通过验证，可以说：

```text
在满足某类历史结构条件的样本中，未来收益分布呈现某种偏移。
```

### 12.2 不可以说什么

不能直接说：

```text
当前一定上涨；
该形态就是买入信号；
历史概率等于未来真实概率；
全历史统计结果适用于所有市场环境。
```

### 12.3 样本不足

建议：

```text
有效样本 < 20：不展示概率，只展示样本不足
20～50：展示并标记低置信度
>= 50：允许正常展示，但仍需说明样本外范围
```

样本数不是质量的全部，跨股票和跨时间稳定性同样重要。

## 13. 当前实验结论

截至 2026-10-11，已完成的 16 只股票跨股票留出实验显示：

- L2 趋势表达式会跨股票重复出现；
- 只看状态或粗幅度时覆盖率较高；
- 加入细幅度、时间和较长上下文后，测试命中率迅速下降；
- 在未见股票、后 30% 时间段的严格测试中，尚未观察到稳定的收益信息增量；
- 当前最值得验证的方向不是继续增加表达式长度，而是使用连续结构特征进行近邻匹配。

因此后续研究默认优先级为：

```text
L2 结构连续特征
> L0/L1/L2 对齐关系
> 最近 K 线归一化形态
> 历史近邻路径分布
> 市场环境分层
```

而不是：


### 16.2 实验结论

当前实验得到以下结论：

1. L2 趋势表达式会跨日期、跨股票重复出现；
2. 只看方向或使用粗幅度时，覆盖率较高；
3. 加入细幅度、时间和更长上下文后，表达式迅速稀疏；
4. 在未见股票、后 30% 时间段的严格样本外测试中，暂未观察到稳定的收益信息增量；
5. 当前最值得继续验证的方向不是继续增加表达式长度，而是使用连续结构特征进行近邻匹配；
6. 精确表达式目前更适合作为历史检索、解释标签和精确匹配基准，不宜直接作为交易信号。

本轮实验不支持以下结论：

```text
某个 L2 表达式可以稳定预测上涨；
表达式的历史概率可以直接作为未来概率；
L2 表达式可以单独生成买卖信号。
```
