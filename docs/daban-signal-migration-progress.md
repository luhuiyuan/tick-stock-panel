## 已确认的公式

D 为观测池日期 T 的上一市场交易日，所有公式输出归属 D，供 T 使用，不重复偏移。

| 原标签 bit / ID | 信号名称 | 条件 |
| --- | --- | --- |
| 0 / t_oversold | 前20日下跌至少15% | C[D]/C[D-20]-1 <= -0.15 |
| 3 / t_mabull | 均线多头 | MA5 > MA10 且 MA10 > MA20 |
| 4 / t_platform | 5日窄幅整理 | W5 <= 0.06 且 -0.05 <= R5 <= 0.05 |
| 5 / t_shrink | 缩量窄幅整理 | mean(A[D-4:D])/mean(A[D-19:D-5]) <= 0.7 且 W5 <= 0.08 |
| 6 / t_uppersh | 长上影 | B > 0 且 U >= 2B |
| 16 / t_highpos | 接近60日最高收盘价 | C[D]/max(C[D-59:D])-1 >= -0.05 |
| 20 / t_lowersh | 长下影 | B > 0 且 Ls >= 2B |
| 57 / t_fake_yin | 假阴真阳 | C[D] < O[D] 且 C[D] > C[D-1] |

W5 = (max(H[D-4:D])-min(L[D-4:D]))/C[D]；R5 = C[D]/C[D-5]-1；B = abs(C-O)/O；U = (H-max(O,C))/O；Ls = (min(O,C)-L)/O。区间均含端点，使用一致复权口径。窗口必须覆盖完整市场交易日；无效/缺失输入为未知，不作为不满足条件参与取反。十字星 B=0 在有效 OHLC 下为 false。

### 定义与因子复用

- 普通信号定义：`backend/app/strategy/premarket_signals.py::SIGNALS`，安装后存放于用户普通信号目录，不依赖旧 `.seeded_v1`，删除后不在启动时自动复活。

- shadow 的共同实体量为 `2*abs(a158_kmid)`，避免再建两个重复因子；其大于零等价于 B>0。
- 非严格比较 >=/<= 使用约 8 个机器 epsilon 的尺度容差消除浮点阈值舍入（例如 `95/100-1`）。严格 >/< 不放宽；未进行收益优化或经济阈值调整。

### 严格契约

`data_contract = {version: 1, inputs: {原始字段: 完整窗口根数}, ohlc_window: N}`：

- 编译后仍是普通 Polars 条件表达式，只在外层加入输入有效性门控。
- 计算调用方提供权威市场交易日集合；普通历史入口默认读取现有日历的内存/本地快照，不联网、不写日历。
- 不用周一至周五猜交易日，不补个股行情值。重复日期、市场日期缺口、窗口不足、非法价格/金额、无穷值和无效分母为未知。
- `inject` 对严格信号缺整列时产出 null，而不是跳过后失去覆盖统计；旧普通信号的默认行为不变。
- 盘中单行路径对本批信号输出 null，不使用当前快照冒充昨日盘前条件。
- `coverage` 分开统计 true / false / unknown；只有明确 true 才能用于候选筛选。不要先 fill_null(False) 再取反。
- 输入必须是同一复权口径的股票日线。按需计算缺基础指标时复用 `compute_indicators`，因子仍复用评分物化链路。
- 契约是显式数据要求，不是通用公式静态推断器。手工改变字段、历史偏移或因子公式时必须同时审查契约窗口/原始输入，不能只改名称就假定新口径已验收。

### 持久化、缓存与升级复核点

- 安装前全批检查 ID/内容冲突；同名不同内容拒绝覆盖；相同定义不重复写；中途写失败回收本次新文件，不动既有用户文件。
- 本次安装在 3018/3011 均无监听的条件下执行；跨进程热安装不在支持范围。当前安装进程注册因子并失效信号表达式缓存；服务未来正常启动按原加载生命周期读新定义。
- API 对旧客户端编辑保留盘上 data_contract；TypeScript 类型支持原样传输。历史不带契约的定义继续可用。
- 资源包导入实测发现预检按 kind=custom 清除了 Alpha158 内置 DSL 因子。新增 `registry.is_builtin_factor`，导入预检仅清理非内置动态因子；不扩大默认 Alpha158 挖掘目录。

均为普通custom、DSL数值定义、无量纲，沿用现有group/status/version等元数据规范。阈值由信号配置，不返回硬编码的标签布尔值。


   ```text
   2 * close / (ts_delay(open, 2) + ts_delay(close, 2))
   ```

   ```text
   (open - ts_delay(high, 1)) / ts_delay(high, 1) * close
   / ts_mean(abs(close - ts_delay(close, 1)), 14)
   ```

### 新增4个可复用数值因子

1. `uf_intraday_range_mean5_20_ratio`：近5日/近20日平均日内振幅。
   ```text
   ts_mean((high - low) / close, 5) / ts_mean((high - low) / close, 20)
   ```
   两窗口都截至D，近5日在20日窗口内。每一天先以当日收盘归一化再求均值；不是5日最高最低区间/20日区间，也不是近5日/此前20日均值。20日平均振幅为0判unknown，近5日振幅为0且20日均值>0时为有效0。
2. `uf_amount_current_mean5_ratio`：当日成交额/含当日的5日均额。
   ```text
   amount / ts_mean(amount, 5)
   ```
   不能误用amount_ratio_5d（它是当日/不含当日的此前5日均额再减1）。均额为0判unknown；当日额0且均额>0时比值0，正常参与条件。
3. `uf_range_8d_low`：8日最高最低区间/区间最低价。
   ```text
   (ts_max(high, 8) - ts_min(low, 8)) / ts_min(low, 8)
   ```
   通过0/8/16偏移得到近、中、远三段。区间最低价必须>0，零宽度有效为0，不能因零宽度而人为判unknown。

   ```text
   ts_mean(amount, 8) / ts_delay(ts_mean(amount, 8), 8)
   ```
