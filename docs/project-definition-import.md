# 项目自定义因子与信号快照

## 使用方式

在「因子库」或「信号库」点击「导入项目定义」。默认显示可导入的缺失定义，可逐项勾选或全选，再点击「确认导入」。信号所需的缺失配套因子会在确认前列出。已安装的相同定义不再写入；同 ID 不同内容的定义和受其影响的依赖链不可导入，不提供覆盖入口。

快照位于 `backend/app/definition_snapshot/`，包括当前服务器的 113 个信号和 100 个自定义因子。Dockerfile 已复制整个 `backend/app`，无需把运行数据目录加入镜像。服务启动不安装快照；项目定义只在用户确认后写入现有 `DATA_DIR/user_data/`。导入立即注册因子并刷新既有缓存，不自动回填行情、计算覆盖榜或新建策略与监控绑定。手动上传资源文件的原入口保持不变。

快照是部署版本的固定内容，线上后续编辑不会反向修改 Git。如果更新快照，应逐条核对 ID、字段和非定义内容，使用隔离目录重新验证。项目入口只追加缺失文件；预览之后本机发生变化时需重新核对。同 ID 冲突必须由使用者在库里明确处理。写入使用同目录临时文件和不覆盖的原子链接；目标数据卷不支持硬链接时，导入会失败并回滚，不降级为覆盖式写入。
