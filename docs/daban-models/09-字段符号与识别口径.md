# 09 字段符号与识别口径

> 本册是全库的**无歧义书写约定**：所有分册里的识别条件都用这里的符号表达，避免「横盘久」「放量强」这类口诀造成理解分歧。
> 符号只是**描述用**，不代表代码里已经存在这些字段；实现状态见 `README.md` 跟踪总表。

---

## 1. 时间下标

| 符号 | 含义 |
|---|---|
| `T` | 涨停当日（本库每笔记录对应的那一天） |
| `T-k` | 涨停日之前第 k 个**交易日**（不是自然日） |
| `T+k` | 涨停日之后第 k 个交易日，**只用于收益/事后标签，禁止进入分类定义** |

价格默认用**前复权**收盘/开高低价。现有计算窗口为 `T-6 ~ T+10`（`win_before=6`、`win_after=10`），若要判定 20/60/100 日形态需把窗口向前扩（这是实现时的第一处改动）。

## 5. 三类口径标记（**无歧义的关键**）

分册每条识别方式都会带以下标记之一，请按此理解：

| 标记 | 含义 | 能否直接当结论 |
|---|---|---|
| **原文定量** | 来源明确给了数字（如「10–30 日」「缩量 30%–50%」「换手 10%–25%」「14:30 后」） | 可作为初始阈值直接试跑，但仍需按本地数据校准 |
| **原文定性** | 来源只有口诀/形容词（「横盘久」「放量强」「长期下跌」），无数字 | **不能**直接实现；本库把它转成可判定条件，并给出「建议口径」 |
| **建议口径** | 我为了消除歧义补的表达式与阈值 | **不是来源结论**，只是第一批试跑起点，必须在观察面板里按分位数校准 |
| **口径未定义** | 量学等专有画线术语（平衡线/精准线/左峰/梯量柱/将军柱），本地无对应字段 | 不臆造替代定义，保留描述并标「受限」 |

**原则**：来源没给数字的地方，绝不把「我建议的阈值」写成来源结论；两者在每条里分开写。

## 6. 状态取值（与 `README.md` 一致）

| 状态 | 含义 |
|---|---|
| **已实现** | 现有代码/字段里已经落地，可直接筛 |
| **部分** | 有近似字段但不完全等价，或该维度只有部分子条件落地 |
| **待实现** | 只用现有日线即可算出，代码还没做 |
| **受限** | 需要本地缺失或覆盖不足的数据源；**仍完整收录识别方式**，不删除 |
| **待补全** | 来源信息不完整，无法给出无歧义识别方式，等待补资料 |
| **方法论约定 / 仅参考** | 不是分类项，是约束、流程或参考模型 |

## 7. 无歧义与防自欺约束

1. **只用 T 日及以前的信息**做分类。`boards`（事后连板数）、`days`、7 个 `r_*` 收益、T+1 及之后的价格**只能作因变量**。
2. **分类多标签、非互斥**：一笔可同时命中多条；须输出重叠矩阵，禁止把标签当正交因子。
3. **不使用未来函数**判定「涨停」：涨停价由板块与 `C_{T-1}` 推算，不用 T 日之后的数据。
4. **样本量门槛**：每档建议 ≥300 笔才看结论；来源 S22 已证明约 46% 的涨停前 5 日是下跌的，单靠动量维度必然误判。
5. **按年份/市场状态分别复现**：S17 指出形态频率随 regime 漂移，全历史汇总比例不能当基准。
6. **样本不独立**：同一连涨段拆成多笔、同股同年多笔高度相关，需按 `(股票, 连涨段)` 聚类做稳健性检查。
7. **归因叙事不作结论**：05 册「主力意图」类只作位置 × 量价的组合标签。
8. **收益留空记录**：末尾持有期未走完的记录收益为空，统计时跳过，但笔数仍计入。
