## 2. 状态定义（图例）

| 状态 | 含义 | 能否直接落地 |
|---|---|---|
| **已实现** | 现有代码/`stats` 字段已落地，可直接筛 | 是 |
| **部分** | 有近似字段但不完全等价，或只有部分子条件落地 | 补一点即可 |
| **待实现** | 只用现有日线即可算出，代码还没做 | 是（优先） |
| **受限** | 需本地缺失/覆盖不足的数据源；**仍完整收录识别方式** | 需先补数据 |
| **待补全** | 来源信息不完整，无法给出无歧义识别方式 | 需补资料 |
| **方法论 / 仅参考** | 约束、流程或参考模型，不是分类项 | 不适用 |

**数据门槛缩写**：`日线` = OHLC+成交额+换手率（本地全历史 4861 交易日）；`扩窗口` = 需把 `win_before` 从 6 扩到 20/60/100；`分钟` = 分钟线（仅 2026-08-31 起）；`盘口` = 五档委托（约 5 天）；`竞价` = 集合竞价（空）；`板块` = 板块归属与板块内统计（空）；`消息` = 公告/舆情/龙虎榜（无）；`资金` = 资金流/北向/融资（待核）。
