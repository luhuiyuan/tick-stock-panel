## 2. 07 册几何形态：为什么只落 1 条

第 17 册落地 8 条后，07 册还剩一批形态。本批逐条探查口径、命中数、分年 CV，结果分成两类：

**可达标（1 条）**：
- **07-01 上升三角形**：近 21 日 3 段，低点逐段抬高（lo₀>lo₁>lo₂）+ 高点基本水平（三段最高差 ≤6%）+ 近段波幅 < 远段。命中 5,047 / CV 0.336，与对称三角 bit79 交集仅 456（9%）——两者确实是两个形态（一个水平阻力、一个下倾阻力），不冗余。

**放弃（5 条，CV 随收紧反而恶化）**：

| 编号 | 形态 | 首轮命中/CV | 收紧后 | 放弃理由 |
|---|---|---|---|---|
| 07-03 | 牛旗 | 66 / 0.499 | — | 命中 <300，急涨+紧凑双条件叠加后样本太少 |
| 07-04 | 牛三角旗 | 1,938 / 0.474 | 667 / 0.471 | CV 始终 ~0.47，且与 07-01 上升三角近义 |
| 07-05 | 平底 | 6,254 / 0.727 | 385 / 1.086 | 收紧振幅后 CV 反升到 1.09，年度分布极不均 |
| 07-07 | 达瓦斯箱体 | 4,668 / 0.556 | 1,002 / 0.751 | 同上，收紧后 CV 升，箱型在打板样本里非稳定形态 |
| 07-10/18 | 突破缺口 | 10,385 / 0.740 | 3,970 / 0.682 | 缺口在打板样本太常见，年度 CV 0.68–0.78 居高不下 |

这些 CV 高不是阈值没调好——收紧后样本下降的同时 CV 反而上升，说明形态出现次数**随年份剧烈波动**（07-26 原文已明确"形态频率随 market regime 漂移"）。按第 17 册确立的判据"CV>0.4 且收紧无改善则不落地"，如实放弃，不硬凑。

**07-20 阶段分析**另作处理：MA20>MA60>c0 上行的 Stage2 判定命中 50,232（34.4%）、CV 0.515，且与 bit60（高位）重叠 51%。它本质是位置分层的顶层维度，不是布尔形态标签，需数值列，不适合塞位掩码。

## 3. 08 册量化因子：原文给了数字的两条

08 册多数条目是"连续特征/方法论"，不宜塞位掩码；但 08-07、08-08 原文明确给了数字阈值，可直接判定化。

**08-08 长下影线**（原文："下影/实体 ≥2 倍"）：
```
lower = min(O_{T-1}, C_{T-1}) − L_{T-1}
body  = |O_{T-1} − C_{T-1}|
hit   = lower ≥ 2·body 且 C_{T-1} ≥ O_{T-1}（收阳/十字星）
```
命中 10,205 / CV 0.226，非常稳定。唯一顾虑是与 bit3（长下影，第 11 册）重叠约 43%——但仍有 5,775 笔独立命中，且 bit3 用的是不同的影线口径（本条严格按原文 2 倍实体），两者不完全等价，判 E\* 并在前端提示登记为"近似但不等价"。

**08-07 动量加速**（原文："量价齐升，成交量 5 日内放大 2 倍以上且价格上涨"）：
```
vr  = A_{T-1} / mean(A_{T-6..T-2})
mom = C_{T-1} / C_{T-6} − 1
```
首轮按原文 VR≥2 / 涨幅≥5% 跑出 31,408（21.5%），过松（"大多数强势股"）。做敏感性分析后收紧到 VR≥3 / 涨幅≥10% → 17,462 / CV 0.186，区分度合理、年度稳定。判 P：原文还有"突破布林上轨/近期高点/筹码密集区"三个子条件，本条只落了量价齐升这一项。

## 4. 02 册回马枪：只落"平台突破型"一档

02-08 原文把回马枪按二拉力度分三档：反包型（最强）/ 平台突破型（标准）/ 超跌反弹型（最弱）。三档是**互斥的强度分档**，本批只落最有代表性、口径最明确的"平台突破型"：

```
前段涨停：T-8..T-20 内存在单日涨幅 ≥9.5% 的 K 线
回调平台：T-2..T-6 最高/最低价振幅 ≤12%
突破确认：C_{T-1} > 平台高点 且 O_{T-1} < 平台高点×1.05（不过度跳空）
```
命中 7,851 / CV 0.378。反包型与已落地的 bit75/76/77（反包三档，第 16 册）高度重叠，超跌反弹型与 bit0（大跌后涨停）重叠，均不单列。判 P：只落三档中的一档。

## 5. pre 属性边界

4 条全为 `pre`，只用 T-1 及以前日线：

- 上升三角形的"向上解决"、突破缺口的"放量跳空确认"这类 T 日动作都不判——bit87 只判到"三角形已成形"。
- 长下影线、动量加速、平台突破的触发都落在 T-1 收盘就有的信息上，无未来函数。
- 这些标签没过样本外验证，不能进 `csg_` 或策略，只做复盘切片。

## 6. 自查与教训

**CV 是硬门槛，收紧未必能救**：本批首次系统性地做"收紧后 CV 反而升"的观察——平底从 0.727 升到 1.086、达瓦斯箱体从 0.556 升到 0.751。这说明当形态本身是 regime 依赖的（熊市多底、牛市多旗），收紧阈值只会把样本压缩到某几个特定年份，年度分布更不均。判据必须是"命中≥300 **且** CV≤0.4"双条件，缺一不可——第 17 册对 3 条 CV>0.4 的给了 P 并落地，本批对 CV 收紧无改善的直接放弃，尺度按形态的 regime 敏感度分层处理。

**探查与生产一致性**：4 条命中数与探查逐条吻合（差 1 笔来自 146144→146146 数据推进），复用第 17 册的 `seg_ext/seg_avg` helper 与 `Hf/Lf/Af` NaN 处理约定，无新增 helper。
