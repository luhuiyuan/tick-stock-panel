# 03 封板质量与分时形态

> 按「涨停当天是怎么封上去的」划分。这类维度决定「买不买得到」和封板强度，但**绝大多数需要分钟线/盘口**，本地数据覆盖极短（分钟线 2026-08-31 起、五档约 5 天、竞价为空）。
> 按用户要求「先不管能不能实现」全部收录，状态栏如实标注数据受限，不删除任何条目。

---

## A. 按 K 线形态分（只需日线，可先做）

### 03-01 一字板
- **别名**：无量封板、开盘一字
- **识别**（原文定性，已可判定化）：`O_T = H_T = L_T = C_T = 涨停价`，全天不开板、成交极少。**现有字段 `yizi_t` 已标记 T 日一字**。
- **所需数据**：日线 OHLC、涨停价
- **状态**：**已实现**（`yizi_t`；现有口径为「一字买不进」标注，未做封板质量分类）
- **出处**：S02、S04、S11、S12

### 03-02 T 字板
- **别名**：T 形板
- **识别**（原文定性，已可判定化）：以涨停价开盘、盘中短暂打开后回封，K 线呈 T 形（`O=H=C=涨停价`，`L < 涨停价`）；原文：**下影越长，次日起涨动能越弱**。细分早盘 T 字（开板短、换手少 → 强）与午后 T 字（开板长、换手大 → 弱）。
- **所需数据**：日线 OHLC、涨停价
- **状态**：**已实现**（L2 bit43 T字板，见第 13 册 E\*：开=高=收（容差 0.5%）+ 下影 ≥1%；原文「下影越长动能越弱」的强弱分档未做；**复盘专用**）
- **出处**：S02、S04、S12

### 03-03 缩量板
- **别名**：缩量涨停、价升量缩（交叉 06-12）
- **识别**（原文定性，已可判定化）：当日封死涨停但成交量**显著低于前一日**（原文对比基准是前一日，不是 5 日均量）。建议口径：`amt_ratio_1 = amount_T / amount_{T-1} ≤ 0.7`。原文：低位启动阶段出现则延续性较强；连续多个缩量一字板一旦开板风险极大。
- **所需数据**：日线 OHLC、成交量
- **状态**：**已实现**（L2 bit44 缩量板，见第 13 册 E 严格等价：`amount_T / amount_{T-1} ≤ 0.7`，数值与基准完全照抄建议口径；**复盘专用**）
- **出处**：S02、S12、S04

### 03-04 换手板（实体板）
- **别名**：充分换手板、震荡封板
- **识别**（原文定性 + 原文定量）：非一字涨停、有明显换手、K 线为实体阳线；原文定量：换手率 **10%–25%**（另一说 ≥10%）；盘中充分震荡后封住，可能多次开板回封。原文评价：最有参与价值、次日抛压小。
- **所需数据**：日线 OHLC、成交量、换手率（`turnover_rate` 字段虽在张量，但历史覆盖极低、各年非 null 仅 0.2%–0.3%，**不可用于分类**，见第 13 册 §5）
- **状态**：部分（L2 bit45 实体换手板，见第 13 册 P：`turnover_rate` 历史覆盖极低（§5），原文换手率 10%–25% 无法计算，改用「实体大阳 ≥3% + 振幅 ≥5% + 下影 ≤9%」代理；**此标签不筛换手率**；**复盘专用**）
- **出处**：S02、S01、S04、S11

### 03-05 放量换手板（分歧转一致）
- **别名**：分歧转一致
- **识别**（原文定性 + 原文定量）：早盘开板、放量换手，午后/尾盘封死，**换手率 10%–25%**，封单逐渐增加、回封不破均价线。
- **所需数据**：日线 OHLC、成交量、换手率；「均价线/封单」需分钟线 → 部分受限
- **状态**：受限
- **出处**：S01、S11、S13

## B. 按开板 / 回封行为分（需分钟线或日线近似）

### 03-06 烂板
- **别名**：反复开板、锯齿板
- **识别**（**原文已给数字**）：收盘虽封死涨停，但盘中**反复开板通常 3 次以上**，分时呈波浪锯齿状，封单不稳。原文并列观点：「烂板出妖股」——有时是主力洗盘，需结合次日竞价判断。
- **所需数据**：分钟线开板次数（`open_cnt ≥ 3`）；日线无法判定
- **状态**：受限
- **出处**：S02、S12、S11、S04

### 03-07 烂板回封（弱转强）
- **别名**：回封板、炸板再封、强分歧转一致
- **识别**（原文定性）：盘中多次开板/炸板，尾盘**放量回封**并最终封死；回封必须有量能支撑，次日高开算走强确认。与 03-06 的区别：本条强调「最终封住且放量」的转强结果。
- **所需数据**：分钟线（开板次数、回封时间、回封量）
- **状态**：受限
- **出处**：S01、S11、S13

### 03-08 炸板回封（强分歧转一致）
- **别名**：21 种模型第 21 条
- **识别**：盘中多次炸板、抛压释放后尾盘放量回封，成交量放大、换手充分，不破均价线。与 03-07 为近义条目，来源不同（S01），保留以便跟踪各来源口径差异。
- **所需数据**：分钟线
- **状态**：受限
- **出处**：S01

### 03-09 秒板 / 冲天炮
- **别名**：开盘急拉涨停、直线封板、竞价抢筹
- **识别**（**原文已给数字**）：开盘后**一两分钟内**（另一说开盘 30 分钟内）直接高开封板并封死，分时近乎垂直、不开板、换手低。常见于消息驱动或论坛热吹。
- **所需数据**：分钟线（`seal_time ≤ 09:32`）
- **状态**：受限
- **出处**：S02、S04、S12、S11、S05

### 03-10 竞价一字板
- **别名**：集合竞价封死
- **识别**：集合竞价阶段即封死涨停、无成交或微量成交，开盘后一字封死。
- **所需数据**：集合竞价明细（本地 `auction` 为空）
- **状态**：受限（数据源缺失）
- **出处**：S01

### 03-11 尾盘板 / 尾盘偷袭板
- **别名**：尾盘拉板、收盘突击板、做线板
- **识别**（**原文已给数字**）：**14:30 之后**（另一说 14:30–14:50、最后 20 分钟）快速拉升封板；此前大半日走势平淡；成交量集中在尾盘、封单一般、次日高开概率低。
- **所需数据**：分钟线（`seal_time ≥ 14:30`）
- **状态**：受限
- **出处**：S01、S02、S04、S05、S11、S12

### 03-12 回首掏
- **别名**：下午偷袭板
- **识别**（原文定性）：上午冲高摸板或上板后炸板回落，随后横盘震荡，**下午突然直线拉涨停**；多见于行情偏弱、资金避开过早拉板，以套利为主。
- **所需数据**：分钟线（上午触板 + 下午封板）
- **状态**：受限
- **出处**：S02、S12

### 03-13 地天板
- **别名**：天地逆转
- **识别**（**原文已给数字**）：从跌停或接近跌停开盘，盘中拉升至涨停，日内振幅极大（跌停→涨停单日实际涨幅 **20%+**），成交量天量、换手极高。
- **所需数据**：日线 OHLC + 涨停/跌停价可近似判定；精确需分钟线
- **状态**：部分（日线可近似）
- **出处**：S01、S02、S12

### 03-14 一字连板龙头（情绪标杆）
- **别名**：连续一字
- **识别**：连续多日一字涨停、成交量极小、封单巨大，成为市场情绪标杆；原文关注点在于「开板后是否爆量」。
- **所需数据**：日线 OHLC、`clu`；封单需盘口
- **状态**：部分
- **出处**：S01

## C. 按分时拉升路径分（韭研公社八类，全部需分钟线）

### 03-15 急拉板（一波封板）
- **识别**：单段快速上行、无明显回落、一气呵成封涨停。
- **状态**：受限 | **出处**：S11

### 03-16 台阶板（阶梯封板）
- **识别**：涨一段 → 小幅回踩 → 再拉升，分时呈阶梯、重心持续上移，主力控盘强。
- **状态**：受限 | **出处**：S11

### 03-17 震荡板（换手封板）
- **识别**：盘中宽幅震荡、换手充足，反复消化抛压后封板。
- **状态**：受限 | **出处**：S11

### 03-18 回封板（分时口径）
- **识别**：首次封板失败回落、资金承接后再度封死。与 03-07 近义，此处按 S11 分时口诀单列。
- **状态**：受限 | **出处**：S11

> 03-15~03-18 的「所需数据」均为分钟线（分时路径 + 封板/开板时点），本地仅覆盖 2026-08-31 起；S11 另有已列于 03-01/03-06/03-09/03-11 的直线板、烂板、一字板、尾盘板，不重复编号。

## D. 封板时间与质量打分维度（可直接作为连续特征）

### 03-19 封板时间四档
- **识别**（**原文已给数字**）：开盘涨停（集合竞价即涨停，最强）／早盘涨停（**10:30 前**，强势、次日溢价高）／中盘涨停（**10:30–14:00**，相对偏弱、需看板块联动）／尾盘涨停（**14:30 后**，持续性最弱）。原则：**封板越早越强**。
- **所需数据**：分钟线 `seal_time`
- **状态**：受限
- **出处**：S02、S13、S05

### 03-20 分时四维度打分
- **识别**（原文定性 + 部分定量）：看 **涨停时间、封单大小、开板次数、成交量** 四个维度组合打分。原文定量：封单达流通盘 **1% 以上**才算有底气；开板 1 次算正常换手、**3 次以上警惕**。
- **所需数据**：分钟线、五档委托、流通股本
- **状态**：受限
- **出处**：S13

### 03-21 封单量维度
- **识别**（原文定性 + 定量）：涨停价挂单量越大越强；原文定量：封单 **百万股以上**、封单/成交比值大；危险信号为封单稀疏、被砸穿后无力回封。
- **所需数据**：五档/逐笔委托（本地约 5 天）
- **状态**：受限（数据源严重不足）
- **出处**：S02、S13

### 03-22 开板次数维度
- **识别**（**原文已给数字**）：开板 0 次或开板后快速回封 = 强；**≥3 次** = 弱/出货嫌疑。
- **所需数据**：分钟线
- **状态**：受限
- **出处**：S13、S02

### 03-23 涨停日量能维度
- **识别**（原文定性）：缩量涨停 = 持股者一致看多（最强）；温和放量 = 健康；**高位爆量** = 对倒出货嫌疑。另有反向口径 S05：量能 < 平时 2 倍视为「假涨停」不参与。
- **所需数据**：日线成交量
- **状态**：部分（L2 bit46 高位爆量板，见第 13 册 P：分档维度只落「高位爆量」一档（`amt_ratio ≥5` 取自 p90 + 位置偏高），缩量/温和放量档待后续；**复盘专用**）
- **出处**：S13、S05

### 03-24 分时信号四类（S05 口径）
- **识别**：① 早盘强势封板（开盘 30 分钟内、不开板）；② 盘中拉升涨停（早盘平稳/横盘，中午或下午突然拉升封死）；③ 尾盘涨停（14:30–14:50 拉升、收盘前涨停）；④ 开板封板（早盘涨停→中途开板→重新封板）。
- **所需数据**：分钟线
- **状态**：受限
- **出处**：S05

### 03-25 质量六维判断表
- **识别**（原文定性对照，六个维度各列「高质量信号 / 危险信号」）：封板时间（10:30 前封死 vs 尾盘突击）／炸板情况（从未打开或快速回封 vs 反复开板锯齿）／封单量（百万股以上、封单成交比大 vs 稀疏被砸穿）／成交量（启动温和放量、封板后急剧萎缩 vs 高位巨量封不稳）／板块效应（龙头领涨、跟风活跃 vs 独涨无跟风）／技术位置（底部启动、突破关键位 vs 高位天量天价）。
- **所需数据**：分钟线、盘口、板块、日线
- **状态**：受限
- **出处**：S02
