# 05 主力意图与驱动成因

> 按「主力为什么拉这个涨停、处在操盘哪个阶段」划分。这类维度是**归因性**的，主观成分最高，识别条件多为「位置 + 量价配合 + 分时行为」的组合；本册尽量转成可判定条件，并明确标注哪些只能靠叙事判断、不宜直接量化。
> 相关工作区已有调研：`../主力行为与操盘阶段识别-调研报告.md`（威科夫方法、坐庄五步曲、可观测量代理学派），其第 7 节明确「状态识别 ≠ 归因解释」，与本册口径一致。

## A. 主力意图三分（S02 口径）

### 05-01 吸筹建仓型涨停
- **别名**：底部吸筹板
- **识别**（原文定性 + 定量）：① 出现在**长时间下跌后的底部区域**；② 量价配合（逐段拉升伴随放量）；③ 涨停次日**常有溢价但缩量回落**。原文策略：等回调到涨停价附近或突破涨停高点后再介入。
- **所需数据**：日线 OHLC、成交量、位置分档（01-19）
- **状态**：待实现
- **出处**：S02、S01

### 05-02 洗盘整理型涨停
- **别名**：中位洗盘板
- **识别**（原文定性 + **定量**）：① 出现在**脱离底部约 30%** 的中位区域；② 分时图常有炸板/烂板现象；③ 次日甚至低开低走继续洗盘；④ 验证口径：次日低开**是否缩量**，缩量回调视为洗盘可加仓。
- **所需数据**：日线 OHLC、成交量；分时炸板需分钟线 → 部分受限
- **状态**：受限
- **出处**：S02

### 05-03 出货派发型涨停
- **别名**：高位出货板（交叉 01-06）
- **识别**（原文定性）：① 高位或历史顶部；② 分时多次开板、**量价背离（放量滞涨）**；③ **封单量明显偏小**。原文结论：应回避。
- **所需数据**：日线 OHLC、成交量；封单/开板需盘口 → 受限
- **状态**：受限
- **出处**：S02、S01

### 05-04 「位置决定性质」
- **别名**：S02 楼主总结的总原则
- **识别**：原文一句话口径 **「位置决定性质，量价合一看」**——即同一封板形态在低位/中位/高位的含义完全不同。这不是独立模型，而是**所有分类必须带位置标签（01-19）**的约束条件。
- **所需数据**：位置分档
- **状态**：待实现（作为交叉维度）
- **出处**：S02

## B. 量价行为信号（多数可用日线）

### 05-05 价升量缩
- **别名**：量价背离看涨、惜售
- **识别**（原文定性，已可判定化）：股价上涨但成交量萎缩；原文口诀「价升量缩，后市必火」，视为强烈看涨。建议口径：`C_{T-1} > C_{T-2}` 且 `amount_{T-1} < amount_{T-2}`，连续 3 日成立即 06-14 三元连动。
- **所需数据**：日线 OHLC、成交量
- **状态**：部分（L2 bit24 价升量缩，见第 11 册）
- **出处**：S03（06-12）

### 05-06 长阴短柱
- **别名**：有底假跌
- **识别**（原文定性，已可判定化）：K 线跌幅大（长阴）但对应成交量很小（短柱），属「有底」的假跌洗盘。建议口径：`ret_1 ≤ -4%` 且 `amount / mean(amount_5) ≤ 0.7`。
- **所需数据**：日线 OHLC、成交量
- **状态**：**已实现**（L2 bit47 长阴短柱，见第 13 册 E\*：`ret1 ≤ -4%` + 量比 ≤0.7；`mean(amount_5)` 窗口具体化为 `amount_{T-1}/mean(amount_{T-6..T-2})`；timing=pre 纯事前，可升 L3 信号候选；同 06-08（06 册不翻））
- **出处**：S03（06-08）

### 05-07 长阳矮柱
- **别名**：抛压小 / 控盘高
- **识别**（原文定性）：K 线涨幅大（长阳）但成交量相对较小（矮柱），说明上方抛压小、主力控盘程度高。
- **所需数据**：日线 OHLC、成交量
- **状态**：部分（L2 bit48 长阳矮柱，见第 13 册 P：原文纯定性，`ret1 ≥5%` 与量比 ≤0.9 为本轮按分位数自定；同 06-09（06 册不翻））
- **出处**：S03（06-09）

### 05-08 倍量伸缩
- **别名**：主力洗盘控盘节奏
- **识别**（原文定性）：成交量柱出现「**倍量 → 缩量 → 倍量**」的规律性伸缩，是主力洗盘、控盘良好的表现。
- **所需数据**：日线成交量序列
- **状态**：部分（L2 bit49 倍量伸缩，见第 13 册 P：原文「倍量→缩量→倍量」纯定性，三比值 1.5/0.7/1.5 由本轮自定；同 06-07（06 册不翻））
- **出处**：S03（06-07）

### 05-09 缩量回调 vs 放量下跌
- **别名**：洗盘/出货判别核心
- **识别**（原文定性，是回马枪十大条件里最关键的一条）：回调过程成交量**逐日萎缩**（第 3 日缩至涨停日峰值量 1/3~1/4，最低点附近现地量）= 主力未出货；回调中量能**不缩反增** = 主力偷偷出货，任何反弹都是逃命波。
- **所需数据**：日线成交量序列
- **状态**：部分（L2 bit50 缩量回调，见第 13 册 P：分档维度只落「缩量回调」一档（三日量递减 + 价跌），「放量下跌」反向档与 1/3~1/4 定量未做）
- **出处**：S06、S02

### 05-10 弱转强
- **别名**：烂板回封转强、竞价弱转强
- **识别**（原文定性 + 定量）：① 分时口径：早盘高开后跳水、分时快速拉回均线、**大单净流入 >1 亿**、**换手率 <10%**；② 封板口径：多次开板后尾盘放量回封、次日高开确认。反向「弱转弱」：拉不回均线、大单净流出 >5000 万、换手 >20%。
- **所需数据**：分钟线、资金流、换手率 → 受限
- **状态**：受限
- **出处**：S16、S01

### 05-11 分歧转一致
- **别名**：放量换手后回封
- **识别**（原文定性）：盘中多空分歧充分换手（换手 10%–25%），午后/尾盘封死涨停、封单逐渐增加，回封不破均价线。
- **所需数据**：分钟线、换手率 → 受限
- **状态**：受限
- **出处**：S01、S11

### 05-12 点火
- **别名**：大资金触发点
- **识别**（原文定性）：某一时刻突然起爆、快速大幅拉升、消灭上方卖盘（千手/万手大单），引发其他资金跟随共同把票拉到板上。**注意：这是分时事件，不是日线形态**。
- **所需数据**：逐笔/分钟成交 → 本地缺失
- **状态**：受限
- **出处**：S12
