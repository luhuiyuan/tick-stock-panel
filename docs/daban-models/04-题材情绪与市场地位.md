# 04 题材情绪与市场地位

> 按「这只涨停在板块/情绪周期里处于什么位置」划分。这类维度大多需要板块归属、板块内涨停统计、情绪周期标签；现有代码已落地 **情绪相位、大盘状态、涨停家数、封板率、晋级率、最高板、炸板数** 7 个市场级字段，正好是这一类最基础的骨架。

---

## A. 市场地位 / 涨停梯队（需板块归属 → 本地受限）

### 04-01 龙头首板
- **别名**：题材启动首板
- **识别**（原文定性）：板块启动时**第一个涨停**的个股，带动跟风股上涨，封单强、量能健康、资金认可度最高。
- **所需数据**：板块归属、同板块当日涨停时间排序 → 受限
- **状态**：受限
- **出处**：S01、S15

### 04-02 跟风补涨板
- **别名**：后排板、跟风板
- **识别**（原文定性）：板块龙头涨停后被动跟涨的个股，封单弱、量能不稳、无独立资金主导；龙头断板后跟风易崩。
- **所需数据**：板块归属、板块内涨停排序 → 受限
- **状态**：受限
- **出处**：S01、S15

### 04-03 空间龙头
- **别名**：全市场高度板
- **识别**：全市场连板高度最高的个股，题材情绪风向标；**现有 `mc`（全场最高板）与 `bp` 可提供近似**。
- **所需数据**：`clu` / `mc` / `bp`
- **状态**：部分
- **出处**：S15、S25

### 04-04 板块龙头
- **别名**：主线核心
- **识别**：该主线内最先启动、号召力最强；板块分歧时最先扛住抛压、板块回流时优先反包。不一定是全市场最高板。
- **所需数据**：板块归属、板块内时序 → 受限
- **状态**：受限
- **出处**：S15

### 04-05 助攻中军
- **别名**：中军
- **识别**（原文定性 + 定量）：盘子偏大（原文量化口径：**市值 > 500 亿**）、不连续一字、多为换手涨停；负责稳住板块重心与流动性。中军率先跳水是板块分化/行情尾声的预警。
- **所需数据**：市值（`mktcap` 已实现）、板块归属 → 部分受限
- **状态**：部分
- **出处**：S15、S16

### 04-06 补涨龙
- **别名**：卡位补涨
- **识别**：龙头打出高度后，同板块内低位启动、卡位走连板的标的；上涨依附龙头高度，龙头断板易 A 杀。
- **所需数据**：板块归属、连板高度 → 受限
- **状态**：受限
- **出处**：S15

### 04-07 零散跟风板
- **别名**：后排小票、杂毛板
- **识别**：跟着板块脉冲蹭热度，无独立逻辑、无资金主动维护，板块稍分化最先炸板掉队。原文：一堆涨停里大部分是这类。
- **所需数据**：板块归属、涨停时序 → 受限
- **状态**：受限
- **出处**：S15

### 04-08 涨停梯队结构
- **别名**：金字塔梯队、梯队断层
- **识别**（原文定性 + 定量）：由高到低为 空间龙头 → 板块龙头 → 助攻中军 → 补涨龙 → 零散跟风；健康结构应呈**金字塔型**。原文量化观察：某日首板占 **78.5%**（73/93）、4–6 板全空即为「梯队断层 / 哑铃型结构」，容错率极低。
- **所需数据**：全市场当日涨停按板位分布（`lu`、`bp` 已实现）→ **可先做**
- **状态**：部分（板位分布已有，梯队完整性指标未实现）
- **出处**：S15、S25

### 04-09 老妖抱团 / 历史辨识度
- **别名**：老妖股、连板记忆
- **识别**（原文定性）：有历史连板高度、控制权变更预期、市场记忆的老票再度活跃；本质是情绪抱团而非价值重估，龙头断板会拖累整个梯队。
- **所需数据**：历史连板高度（可由 `streaks.parquet` 近似）、题材归类
- **状态**：待实现
- **出处**：S26

## B. 情绪周期与市场环境（多数已实现）

### 04-10 情绪相位六分
- **别名**：冰点 / 修复 / 点火 / 主升 / 高潮 / 退潮
- **识别**：按连板梯队与日频情绪标签划分的六相位。**现有 `ph` 字段已实现**，且 `cond_masks` / 前端 LIMITS 已有「只在某相位交易」「冷相位」「点火+主升才买」等筛选项。
- **所需数据**：`ph`（已实现）
- **状态**：**已实现**
- **出处**：S05（战法语境）、本地 `regime_history`

### 04-11 大盘状态三分
- **别名**：强 / 中 / 弱
- **识别**：**现有 `st` 字段已实现**，前端已有「只在大盘强时买」「避开大盘弱」两条限制。
- **所需数据**：`st`（已实现）
- **状态**：**已实现**
- **出处**：本地 `regime_history`

### 04-12 涨停家数
- **别名**：赚钱效应广度
- **识别**：当日全市场涨停家数。**现有 `lu` 字段已实现**，前端有 ≥30 / ≥50 / ≥80 三档限制。
- **所需数据**：`lu`（已实现）
- **状态**：**已实现**
- **出处**：S01、S16、本地 `regime_history`

### 04-13 封板率
- **别名**：封板成功率
- **识别**：**现有 `seal` 字段已实现**，前端有 ≥70% / ≥80% 两档限制。原文情绪量化口径：炸板率 <20% 属上升期、20%–40% 分歧期、>40% 退潮期。
- **所需数据**：`seal`（已实现）
- **状态**：**已实现**
- **出处**：S16、本地 `regime_history`

### 04-14 晋级率
- **别名**：连板晋级率
- **识别**：**现有 `promo` 字段已实现**，前端有 ≥30% / ≥40% 两档限制。
- **所需数据**：`promo`（已实现）
- **状态**：**已实现**
- **出处**：本地 `regime_history`

### 04-15 最高连板高度
- **别名**：空间高度
- **识别**：**现有 `mc` 字段已实现**，前端有「全场最高板 ≤7 / ≤5」两档限制。原文量化：最高连板 >5 板属上升期、3–5 板分歧期、<3 板退潮期。
- **所需数据**：`mc`（已实现）
- **状态**：**已实现**
- **出处**：S16、本地 `regime_history`

### 04-16 炸板数
- **别名**：首板日炸板数
- **识别**：**现有 `brk` 字段已实现**（`broken_limit`）；原文另有「首板日炸板数 ≤20」条件。
- **所需数据**：`brk`（已实现）
- **状态**：**已实现**
- **出处**：本地 `regime_history`

### 04-17 情绪周期三分（量化口径）
- **别名**：上升期 / 分歧期 / 退潮期
- **识别**（**原文已给完整数字**）：
  - 上升期：昨日涨停股平均涨幅 **>3%**、涨停数 **>80 家**、跌停数 **<5 家**、炸板率 **<20%**、最高连板 **>5 板**、北向净流入 >30 亿、融资余额环比上升；
  - 分歧期：昨日涨停股平均涨幅 **0–3%**、涨停数 **30–80 家**、跌停 **5–10 家**、炸板率 **20%–40%**、最高连板 **3–5 板**；
  - 退潮期：昨日涨停股平均涨幅 **<0**、涨停数 **<30 家**、跌停 **>10 家**、炸板率 **>40%**、最高连板 **<3 板**、北向净流出 >20 亿。
- **所需数据**：涨停/跌停家数、炸板率、最高板（均已有）；北向资金、融资余额、昨日涨停股平均涨幅 → 本地待核
- **状态**：部分（前 5 项已有，后 3 项待补）
- **出处**：S16

### 04-18 情绪周期适配规则
- **别名**：修复期做、退潮期停
- **识别**（原文定性 + 定量）：情绪启动/发酵期成功率最高；分歧期只做主线；**退潮期坚决不做**。原文可操作环境量化：昨日涨停指数涨幅为正、炸板率 **<30%**、连板高度 ≥3 板。
- **所需数据**：`ph`、`seal`、`mc`（已实现）
- **状态**：部分（字段已有，规则未实现）
- **出处**：S06

### 04-19 板块效应 / 板块热度
- **别名**：主线题材识别
- **识别**（**原文已给数字**）：绝对龙头 = 连续 ≥3 个涨停、板块内涨停家数 **>10 家**、成交额占板块 **>5%**；板块梯队 = 中军（市值 >500 亿）涨停 + 低位跟风（一板二板）**>5 家** + 板块成交额占全市场 **>10%**；新题材介入条件 = 连续 2 天涨停家数 **>15 家** + 明确政策/事件驱动 + 梯队完整。
- **所需数据**：板块归属、板块成交额 → 受限
- **状态**：受限
- **出处**：S16、S02

### 04-20 题材三级
- **别名**：主线 / 新题材 / 冷门题材
- **识别**（原文定性）：主线题材回马枪最优（有板块效应与龙头背书）；新题材次优（爆发力强、不确定性大）；冷门题材谨慎（题材过气、纯个股行为）。验证条件：回调期间板块内其他个股没有集体崩盘、题材逻辑未被证伪。
- **所需数据**：板块归属、题材生命周期 → 受限
- **状态**：受限
- **出处**：S06

## C. 消息 / 成因 / 题材驱动（本地无消息数据源）

### 04-21 利好刺激板
- **别名**：消息驱动板
- **识别**（原文定性）：突发利好公告（业绩预增、重组、政策利好），股价一字或高开秒封；持续性取决于利好级别，逐级开板看换手。
- **所需数据**：公告/新闻 → 本地缺失
- **状态**：受限
- **出处**：S01、S05

### 04-22 利空出尽板
- **别名**：错杀反弹、利空落地
- **识别**（原文定性）：突发利空公告（业绩亏损、监管问询）后低开下杀，随后**放量涨停**、利空出尽转多；原文强调须「站稳平台」「破前低后反转」。
- **所需数据**：公告/新闻、日线 OHLC → 部分受限
- **状态**：受限
- **出处**：S01

### 04-23 业绩驱动涨停
- **别名**：财报涨停
- **识别**（原文定性 + 定量）：财报后第二天涨停、**量能 < 平时 1.5 倍**、后续走势平稳。
- **所需数据**：财报日期（`financials` 可能有）、日线量能
- **状态**：待实现（需核财报日期可用性）
- **出处**：S05

### 04-24 题材炒作涨停
- **别名**：板块整体涨停
- **识别**：板块整体涨停、量能巨大、接力速度快。
- **所需数据**：板块归属 → 受限
- **状态**：受限
- **出处**：S05

### 04-25 主力推动涨停
- **别名**：独立涨停
- **识别**：个股独立涨停（板块没动）、量能配合、走势异常强。原文：3 类涨停股中识别难度最高。
- **所需数据**：板块归属、日线量能
- **状态**：部分
- **出处**：S05

### 04-26 涨停三种成因
- **别名**：业绩 / 题材 / 主力三分
- **识别**：这是**成因维度的顶层分类**，04-23/24/25 为其三个取值；用于给每笔涨停打「为什么涨」的标签。属多标签而非互斥（可同时是题材 + 主力）。
- **所需数据**：公告、板块、资金流
- **状态**：受限
- **出处**：S05
