## A. 反包与二次启动类

### 02-01 反包涨停（阳包阴）
- **别名**：反包板、阳包阴、弱转强
- **识别**（原文定性，已可判定化）：T-1 收阴线/十字星/假阴线，T 日**放量涨停且实体完全吞没 T-1 实体**，收盘过前高。建议口径：`C_{T-1} < O_{T-1}` 且 `C_T > max(O_{T-1}, C_{T-1})` 且 `H_T > H_{T-1}`，`amt_ratio ≥ 1.2`。
- **所需数据**：日线 OHLC、成交量
- **状态**：待实现
- **出处**：S01、S02、S04

### 02-02 反包细分型
- **别名**：反包阴 K 板 / 反包十字星板 / 反包假阴线板 / 断板反包
- **识别**：按 T-1 形态细分 02-01：① 昨日涨停炸板未封、收长上影，今日涨停反包；② 首日涨停、次日断板、第三日涨停反包；③ T-1 为十字星或假阴真阳。原文另注：**反包时量能缩小，信号更强**。
- **所需数据**：日线 OHLC、成交量；「炸板」需 `H` 触涨停价（可由涨停价推算，不必须分钟线）
- **状态**：待实现
- **出处**：S01、S02、S12、S04

### 02-03 双响炮 / N 字板
- **别名**：N 字结构、涨停-缩量回调-涨停
- **识别**（原文定性，已可判定化）：① 前置涨停；② 缩量回调且**不破位**；③ 再次涨停并突破前高。建议口径：`days_since_lu ∈ [2,10]`，回调期 `amt_shrink ≤ 0.7`，T 日 `C_T > 前高`。
- **所需数据**：日线 OHLC、成交量、`clu`
- **状态**：待实现
- **出处**：S01、S06

### 02-04 回马枪（基础结构）
- **别名**：涨停回马枪、龙回头（近似）
- **识别**（**原文已给完整量化条件，十条**）：① 前置涨停 1–2 个（≤3），且为实体板、10:30 前封、非尾盘板/烂板；② 前置涨停位置低/中位，本轮累计涨幅 ≤ 50%；③ 回调 **2–5 日**（强势 2–3、普通 3–5、弱势 ≤7、>10 淘汰）；④ 回调幅度 ≤10% 最强、**15–25% 标准**、25–35% 可接受、>35% 或跌破涨停阳线开盘价淘汰；⑤ 量能三段：涨停日量比 1.5–3 倍 → 回调第 3 日缩至峰值量 **1/3~1/4** → 二拉日放量达涨停日 **70%–100%**；⑥ 支撑位（涨停实体下沿 / 10 或 13 日线 / 启动平台 / 黄金分割 0.382）止跌，多支撑共振最佳；⑦ 5/10/20 日多头排列，10 日线不有效跌破（连续 2 日收盘站不回且放量）；⑧ 有题材（主线 / 新题材 / 冷门三级）；⑨ 流通市值 **20–80 亿**、涨停前 20 日日均成交额 ≥ 5000 万、二拉成交额 1–5 亿；⑩ 二拉 10:30 前封板、分时流畅、封板后缩量。
- **所需数据**：日线 OHLC、成交量、市值、均线；**封板时间/分时**需分钟线 → 受限
- **状态**：受限（日线部分可先做）
- **出处**：S06

### 02-05 回马枪·按前置涨停数
- **别名**：单板 / 双板 / 三板回马枪
- **识别**（原文定性）：单板 = 1 个涨停后回调再涨停（最安全）；双板 = 2 个涨停后回调再涨停（动能强、需更好环境）；三板 = 3 个涨停后回调（多为出货反抽，不建议）。
- **所需数据**：`clu`、日线 OHLC
- **状态**：待实现
- **出处**：S06

### 02-06 回马枪·按回调形态
- **别名**：V 型 / W 型 / 平台型回马枪
- **识别**（原文定性）：V 型 = 快速回调 2–3 日后 V 型反转涨停（爆发强、持续弱）；W 型 = 第一次反弹不涨停、二次回调不创新低、再二拉（结构稳）；平台型 = 小区间横盘约 5 日后放量突破（洗盘最充分、空间最大）。
- **所需数据**：日线 OHLC、成交量
- **状态**：待实现
- **出处**：S06

### 02-07 回马枪·按回调幅度
- **别名**：横盘强势型 / 浅回调型 / 深回调型
- **识别**（原文定性 + 胜率参考）：横盘强势型 = 涨停价附近横盘 3–5 日、重心不下移（成功率约 60–70%）；浅回调型 = 回调 15–20%、跌到 10 日线止跌（约 50–60%）；深回调型 = 回调 >30%、接近启动点（约 40%）。
- **所需数据**：日线 OHLC、成交量、MA10
- **状态**：待实现
- **出处**：S06

### 02-08 回马枪·按二拉力度
- **别名**：反包型 / 平台突破型 / 超跌反弹型二拉
- **识别**（原文定性）：反包型 = 二拉涨停收复全部回调失地甚至创新高（最强）；平台突破型 = 二拉突破回调期震荡平台高点（标准、最常见）；超跌反弹型 = 仅从低位反弹、未突破任何关键位（最弱，多一日游）。
- **所需数据**：日线 OHLC
- **状态**：待实现
- **出处**：S06

### 02-09 回马枪·按题材属性
- **别名**：主线 / 独立 / 消息回马枪
- **识别**（原文定性）：主线 = 当前主线板块内、有板块效应（成功率最高）；独立 = 无板块效应、个股独立行情（成功率低）；消息 = 突发消息涨停、回调后消息继续发酵（不确定性大）。
- **所需数据**：板块归属、板块内涨停统计 → 本地受限
- **状态**：受限
- **出处**：S06

### 02-10 回马枪·真假鉴别（避坑清单）
- **别名**：假回马枪八坑
- **识别**（原文定性，可直接转否定条件）：① 高位回马枪（已涨 1 倍以上）；② 放量回调（量不缩反增）；③ 破位（跌破涨停启动价 / 20 日线）；④ 超时（回调 >7 日）；⑤ 无量二拉；⑥ 孤板（无板块效应）；⑦ 尾盘偷袭板（14:30 后）；⑧ 退潮期硬做。
- **所需数据**：日线 OHLC、成交量、市场情绪；部分需板块/分钟数据
- **状态**：受限
- **出处**：S06

- **所需数据**：日线 OHLC
- **状态**：待实现
- **出处**：S14

### 02-12 倒锤头线 / 锤头线
- **别名**：Inverted Hammer / Hammer
- **识别**（原文定性，已可判定化）：出现在下跌后底部或上涨回调位，实体小、**上影长**、下影短或无；原文强调「缩量下跌后的底部区域」为试盘/吸筹信号。建议口径：`upper_sh ≥ 2×body`、`lower_sh ≤ 0.2×body`，且 `amt_shrink ≤ 0.8`。
- **所需数据**：日线 OHLC、成交量

### 02-15 四连阳一阴切线

### 02-16 V 型反转 + 一阴切线
